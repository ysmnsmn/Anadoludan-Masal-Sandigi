# Anadolu'dan Masal Sandığı

## Proje Hakkında

Anadolu'dan Masal Sandığı, Anadolu kültürüne ait masalları dijital ortamda okuyucularla buluşturmak amacıyla hazırlanmış bir web sitesidir.

Proje kapsamında kullanıcılar masalları görüntüleyebilir, arama yapabilir, kategorilere göre filtreleyebilir ve beğendikleri masalları favorilerine ekleyebilir.

## Kullanılan Teknolojiler

- HTML: Web sayfasının yapısını oluşturmak için kullanılmıştır.
- CSS: Sayfanın tasarımını, renklerini ve düzenini oluşturmak için kullanılmıştır.
- JavaScript: Arama, filtreleme, favorilere ekleme ve yazı boyutunu değiştirme gibi etkileşimleri sağlamak için kullanılmıştır.

## Nasıl Açılır?

1. GitHub deposundan `index.html` dosyasını indirin.
2. Dosyayı bilgisayarınızda bir web tarayıcısıyla (Chrome, Safari vb.) açın.
3. Web sitesi kullanıma hazır olacaktır.
